# Komentář k zákonu č. 326/2004 Sb., o rostlinolékařské péči a o změně některých souvisejících zákonů

Otevřený komentář k zákonu o rostlinolékařské péči — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; ochrana rostlin proti škodlivým organismům, opatření proti zavlékání, přípravky na ochranu rostlin a pomocné prostředky, mechanizační prostředky, orgány, přestupky a odborná způsobilost.

Konsolidované znění: dokument e-Sbírky `SB-2004-00326_2025-04-01`.
